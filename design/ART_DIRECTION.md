# 美术方向

- targetFinish：whitebox；风格化彩绘微缩棋子，可切换素模检查轮廓。
- 镜头：斜 45° 左右正交视角，可旋转、缩放、平移。棋盘和合法操作优先于装饰。
- 龙族：暖金、赤铜与余烬色；翼、角、竖直晶体构成高而展开的轮廓。异潮：青绿生物荧光与深紫甲壳；低伏、触肢、卵形和尖刺构成轮廓，保持原创，不复制现有影视形象。
- 所有棋子有统一尺度底座；种族同时由底座边数、轮廓与图标区分，不只依赖颜色。地形低对比，棋子高对比；河流、高地和菌毯具有独立形状语言。
- 绿色格表示部署/移动，红色标记表示攻击目标，悬浮菱形表示被围。被围同时使用暗化与图标；生命条和文字提供非颜色冗余。
- HUD 首层为回合、指挥点、手牌和结束回合；次层为选中对象、种族能力和日志。中文短句，避免覆盖棋盘焦点。
- 关键时刻：完成包围后，出口消失、菱形出现、功能建筑贡献停止、防御塔射程缩短；无需粒子遮蔽棋盘。
- 必需资产：棋盘、地形、两族核心/兵种/功能建筑/防御建筑、状态标记、卡框。可降级项：复杂材质、动态特效、正式插画与音频。
- 首版资产均为程序化原创几何；后续正式模型可替换，但不得降低棋子、地形和状态的可读性。声音方向首版 N/A。
- 正式资产生产已选定单一 AI 3D 路线：同一风格提示体系生成棋子、建筑、模块地形与生态组件，代码只做统一比例、材质、组装和整体飞行动态，不混入手工建模或来源不一的素材包。卡牌图从同一批 3D 模型渲染。
- 首批校准仅限龙、异潮、火山地块、菌毯组件各一件；验收前不得扩批。Tripo 调用配置与 API 密钥当前缺失，因此尚未生成正式资产或产生调用费用。
