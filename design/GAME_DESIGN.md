# 游戏设计

## 体验与循环

玩家是微缩棋盘上的军团统帅，通过卡牌建设战争体系，再以移动、攻击和包围瓦解对方。体验承诺是“围而不攻也能改变战局”；experienceProfile 为 system-led。核心循环：抽牌与获得指挥点 → 部署兵种/建筑或释放技能/环境 → 移动或攻击 → 结算包围 → 结束回合并由防御塔自动攻击 → 摧毁对方核心或重开。

先例借用 RTS 的建设与兵种克制、回合战棋的确定性行动、围棋的连接与出口；不采用实时操作、随机命中或直接围杀。卡牌决定可部署与可释放的手段，棋盘实体持续存在，移动和攻击不需要再次抽牌。

## 世界规则

- 12×12 四邻接棋盘；平原、森林、高地、河流清晰可见。河流阻挡地面单位，高地为未被围棋子减伤。
- 玩家公开看到全部棋子、地形、手牌和状态；没有隐藏信息。抽牌使用固定 seed，战斗无随机命中。
- 每回合获得基础指挥点并抽牌；未被围功能建筑额外提供指挥点，并在建成时向本局牌库注入新卡。
- 单位每回合可移动或攻击一次，新部署单位下回合行动。建筑不移动。防御塔在所属方回合结束自动攻击。
- 相连友方棋子组没有可通行出口即被围。被围单位移动与攻击下降；功能建筑停止贡献；防御塔射程缩短。高地减伤同时失效。
- 龙族飞行单位可越过河流，被围时移动不受削弱；巨龙攻击产生范围伤害。异潮菌毯构成额外通路，菌毯上的异潮单位被围时不受攻防削弱。
- 核心生命归零即落败；页面明确显示胜方并可开始新局。

## 决策、反馈与重开

玩家在歼灭、建设、抢地形与包围之间分配指挥点和单位行动。功能建筑值得保护，防御塔既能攻击也能参与封锁。每次输入只执行规则核心认可的行动；合法目标、被围菱形标记、生命变化、建筑禁用和日志提供反馈。失败必须能追溯到核心被摧毁，下一局可改变建设顺序或包围路线。

初态为双方各一座核心、一手固定起始卡和固定 seed 牌库。另设包围演示局面，用于直接观察包围前后差异。叙事附件与 signature_command：N/A。

## 可执行切片与验证

最大风险：包围是否成为比直接换子更有意义的行动，且玩家能否读懂建筑被围后的变化。最小路径：部署 → 移动/攻击 → 结束回合 → 建功能建筑并验证贡献 → 完成包围并验证单位/塔/功能建筑变化 → 飞行越障与菌毯反例 → 摧毁核心 → 重开。

若玩家无法预判包围、建筑停用不可见、卡牌随机性破坏确定性行动，或最优行动始终只是直接攻击，则需修改设计。首版不验证长期平衡、AI、联网和正式美术成色。
